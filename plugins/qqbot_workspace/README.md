# 蓝铃个人工作区

蓝铃的文件工具以 `D:\project\lanling` 为固定读写工作区。她可以自己组织笔记、学习资料和待办文件。其他本机盘符路径提供只读访问，实际可读范围取决于运行账号已有的 Windows 权限。

## 启用

将 `config.example.toml` 复制为本机 `config.toml`，设置 `plugin.enabled = true`，并把 `[workspace].owner_session_id` 绑定到 `qqbot_identity` 所配置主人的已有私聊。该值取自已有 `chat_sessions.session_id` 或聊天管理信息，不填 QQ、昵称或自行计算的 ID。本机配置不进入 Git；更换主人或绑定会话后重启插件。

插件只在蓝铃实例运行。Host 使用真实会话上下文将四个工具限制在绑定的私聊；每次调用还通过身份插件和公开聊天查询核对当前主人。该私聊的原生主动续聊也可以使用文件工具。群聊和其他私聊不开放电脑文件入口。

## 文件工具

在主人私聊中由 Planner 按需要通过 `tool_search` 查找：

| 工具 | 用途 |
| --- | --- |
| `lanling_list_directory` | 浏览本机目录，每页最多 100 项；相对路径从工作区开始。 |
| `lanling_read_file` | 分页读取 UTF-8、带 BOM 的 UTF-16、GB18030 文本，并返回 SHA-256。 |
| `lanling_write_file` | 在工作区保存完整 UTF-8 文本，自动创建父目录；覆盖已有文件须提供刚读取的 SHA-256。 |
| `lanling_manage_file` | `mkdir` 建目录，`copy` 把本机文件复制进工作区，`move` 在工作区内移动，`trash` 移入工作区 `.trash/`。 |

例如，可以在私聊中让她把一份本机资料复制进工作区，再把阅读笔记存到 `notes/滑板入门.md`。文件夹和文件名由她按需要选择。工具返回成功才表示保存完成；归档结果返回恢复所需的实际路径，可用 `move` 移回一个尚不存在的位置。

文本读取的原文件上限为 4 MiB；每次最多返回 300 行、16000 字符，结果中的 `next_line` 指示后续页。写入单次最多 256 KiB，文件复制最多 80 MiB。当前工具读取文本；其他格式可以复制保存原件，内容理解仍需对应的媒体或文档能力。

## 权限边界

写入、目录创建、移动和归档逐次检查固定工作区。Windows 设备路径、UNC、备用数据流、歧义文件名以及写入路径上的符号链接、目录联接和其他重解析点会被拒绝。文本保存采用同目录临时文件后替换目录项，避免原地改写硬链接的外部内容。工具不提供命令、脚本执行或系统权限修改。

此边界约束模型通过本插件发起的文件操作。MaiBot、NapCat 和其他插件仍按原部署维护数据库、配置与缓存；本插件不改变整个进程的 Windows 账号权限，也不构成对同账号其他进程的系统隔离。读取的文件内容会进入当前模型请求和会话工具记录，不能把“只读”理解成“不会发送给模型”。

本插件提供保存和回读资料的工具。自主目标、B站搜索与后台学习调度由相应能力另行接入；写下一项计划不代表后台任务已经运行。
