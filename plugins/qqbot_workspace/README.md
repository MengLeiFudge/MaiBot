# 蓝铃工作区与项目文件

蓝铃的文件工具对以下两处目录及全部子目录提供读写能力：

- 个人工作区 `D:\project\lanling`：组织笔记、学习资料和待办文件。
- 蓝铃项目 `D:\project\qqbot\maibot-lanling`：完整访问项目中的配置、提示词、数据和源码，不按配置字段或文件用途另设授权。

其他本机位置提供只读访问。实际文件操作受运行账号已有的 Windows 权限和文件占用状态约束。

## 启用

将 `config.example.toml` 复制为本机 `config.toml`，设置 `plugin.enabled = true`，并把 `[workspace].owner_session_id` 绑定到 `qqbot_identity` 所配置主人的已有私聊。该值取自已有 `chat_sessions.session_id` 或聊天管理信息，不填 QQ、昵称或自行计算的 ID。本机配置不进入 Git；更换主人或绑定会话后重启插件。

插件只在蓝铃实例运行。Host 使用真实会话上下文将四个工具限制在绑定的私聊；每次调用还通过身份插件和公开聊天查询核对当前主人。该私聊的原生主动续聊也可以使用文件工具。群聊和其他私聊不开放电脑文件入口。Planner 和 Replyer 使用同一份权限说明；提示词约定新增功能由主人维护，项目设置及内容按主人后续指导处理。

## 文件工具

在主人私聊中由 Planner 按需要通过 `tool_search` 查找：

| 工具 | 用途 |
| --- | --- |
| `lanling_list_directory` | 浏览本机目录，每页最多 100 项；相对路径从工作区开始。 |
| `lanling_read_file` | 分页读取 UTF-8、带 BOM 的 UTF-16、GB18030 文本，并返回 SHA-256。 |
| `lanling_write_file` | 在个人工作区或蓝铃项目保存完整 UTF-8 文本，自动创建父目录；覆盖已有文件须提供刚读取的 SHA-256。 |
| `lanling_manage_file` | `mkdir` 建目录，`copy` 复制本机文件到任一可写目录，`move` 在两处目录中移动，`trash` 统一移入个人工作区 `.trash/`。 |

相对路径默认从个人工作区开始。项目文件使用完整的 Windows 路径，或对应的 `/mnt/d/project/qqbot/maibot-lanling/...` 路径；工具将 `/mnt/<盘符>/...` 转为本机 Windows 路径。

个人资料的文件夹和文件名由她按需要选择，项目文件按主人的具体指导处理。工具返回成功才表示保存完成，配置是否已由框架加载须另行核对。归档结果返回原位置和恢复所需的实际路径，可用 `move` 移回一个尚不存在的位置。

文本读取的原文件上限为 4 MiB；每次最多返回 300 行、16000 字符，结果中的 `next_line` 指示后续页。写入单次最多 256 KiB，文件复制最多 80 MiB。当前工具读取文本；其他格式可以复制保存原件，内容理解仍需对应的媒体或文档能力。

## 权限边界

写入、目录创建、移动和归档逐次检查个人工作区与蓝铃项目两个根目录，目录内不设置文件或配置字段白名单。具体如何使用项目文件由提示词和主人指引约束。Windows 设备路径、UNC、备用数据流、歧义文件名以及写入路径上的符号链接、目录联接和其他重解析点会被拒绝。两个根目录本身保持在原位置，归档统一进入个人工作区 `.trash/`。

文本保存采用同目录临时文件后替换目录项，避免原地改写硬链接的外部内容。工具不提供命令、脚本执行或系统权限修改。

此边界约束模型通过本插件发起的文件操作。MaiBot、NapCat 和其他插件仍按原部署维护数据库、配置与缓存；本插件不改变整个进程的 Windows 账号权限，也不构成对同账号其他进程的系统隔离。读取的文件内容会进入当前模型请求和会话工具记录，不能把“只读”理解成“不会发送给模型”。

本插件提供保存和回读资料的工具。自主目标、B站搜索与后台学习调度由相应能力另行接入；写下一项计划不代表后台任务已经运行。
