# QQBot 视频与历史阅读

普通图片和表情交给 MaiBot 原生多模态处理，本插件不再设置入站图片门控或补充引用图片描述。Planner 和 Replyer 使用 `[visual]` 的 `multimodal` 模式，所选模型须实际支持视觉；表情收集沿用原生配置。消息处理遵守根工作区的 [消息完整性与按需触发](../../../docs/message-context.md)。

插件保留视频分镜与当前会话的更早历史查阅。视频原图直接交给主模型，不额外请求摘要模型，使用方式见 [视频分镜](VIDEO.md)。

上文不足时，通过原生 `tool_search` 发现并调用 `read_chat_history`。默认每页30条，`count` 可取1–100；使用返回的 `next_before_message_id` 连续向前翻页。工具只读取运行时当前会话，保留说话者、时间、引用和来源树，图片以实际 `content_items` 返回；同刻消息也能稳定翻页，不受近期聊天窗口条数限制。不会每轮自动补读历史或增加历史提示 Hook。

旧附件缺少原图时，通过公开 NapCat 原消息和图片下载 API 恢复，核对原消息 ID、发送者和会话。仅使用协议返回的文件或 base64，不读取聊天正文中的磁盘路径。单张失败保留其他消息与图片，并明确说明未取得，不能把占位当作已经看过。

将 `config.example.toml` 复制为本机 `config.toml` 后启用；本人 QQ 通过公开配置热重载。日志只记录配置状态、源消息 ID 和错误类型，不记录消息、图片或账号内容。
