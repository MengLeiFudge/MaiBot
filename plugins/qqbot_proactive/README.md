# QQBot 私聊主动续聊

`qqbot_proactive` 为独立机器人提供话题延续和日常关心。把 `config.example.toml` 复制为本机 `config.toml`，将 `[plugin].enabled` 设为 `true`，并确认 `[proactive].bot_qq` 对应本实例。主人账号只从 `qqbot_identity` 的本机 `[identity].owner_qq` 读取。插件仅处理这个账号的已有 QQ 私聊，不处理群聊或创建陌生人会话。

## 联系节奏

插件每 15 秒检查消息。新消息后随机空闲 180–300 秒再考虑续聊，范围由 `min_idle_seconds`、`max_idle_seconds` 控制。尚未回答的主人消息优先交给正常聊天链路；十分钟仍无回复时允许重新判断是否有回应价值，不会因此永久停止主动联系。

`max_unanswered_turns` 默认 2：无人回应时实际发出两轮后，之后每轮间隔至少随机 2–3 小时，由 `min_retry_seconds`、`max_retry_seconds` 控制。收到主人新消息后恢复短间隔。模型决定等待时可自行选择 5 分钟至 24 小时后的下一次检查，无人回应两轮后的长间隔下限仍有效。请求失败或入队后没有观察到实际发言不消耗轮数，按长间隔退避。

计数依据是主动任务预留时间之后、没有主人新消息时观察到的机器人消息。框架在发送成功后才将消息写入记录；同次回复拆分出的多条只计一轮。公开消息接口没有主动任务 ID，因此同一空闲窗口内其他来源的机器人消息也可能计入一轮，不能严格归因到某个主动任务。

## 话题与表达

仅在空闲到期时，通过公开 `llm.generate` 调用现有 `planner` 模型一次，推理与 JSON 正文共享 8192 token 上限，模型等待上限 60 秒，整轮检查上限 90 秒。读取最近 24 条私聊文本（每条最多 800 字）和已有话题，判断是否适合联系。最新主人消息若不在这 24 条内则额外补入。普通回复不经过这一步。最多保留三个待跟进话题，每个必须引用真实主人消息或已有话题的来源 ID；来源七天后过期。模型负责移除已经完成、否定或不愿继续的话题，也负责判断关心时机，内容理解仍可能有误。

明确要求不要打扰或停止主动联系时，持久保存静默状态，直到主人再次说话。临时忙碌、睡觉或道别按上下文安排有限等待，到期重新考虑；单纯未回复不等于拒绝。没有适合的新内容时允许不发，不为了凑数生成固定问候。模型判断结束后重新核对身份、最新消息和计划，期间有新交流或计划变化就丢弃过时决定。

最终通过 `maisaka.proactive.trigger` 交给原生 Planner/Replyer 表达。插件提供话题方向，保留现有人设、称呼、语气、消息拆分及打字延时；不直接发送固定文案。已在框架入队的任务仍由框架执行，插件提示其以新消息为先，无法撤销已入队任务。

## 自己安排后续联系

Planner 可以通过 `tool_search` 查找 `schedule_private_followup`：`schedule` 安排 300–86400 秒后重新考虑联系，`cancel` 取消当前计划。安排必须引用同私聊七天内的真实主人消息 ID，并给出不超过 400 字的联系方向。一个私聊保留一个计划，新计划覆盖旧计划，跨重启保留；无法取得来源或身份不符时不创建。

普通规划 Hook 只提供工具说明，不额外调用模型。到期由后台模型结合最新对话判断，允许继续等待或放弃，随后消费这次计划；已完成的事情不要求机械执行。新消息会恢复短间隔额度并在到期判断时纳入上下文；已有指定时间优先于普通空闲间隔。临时忙碌通常适合安排稍后关心，明确不要打扰时保持静默。

这是一套聊天联系计划，不是保证准点送达的提醒服务。程序需要运行；检查有 15 秒粒度，另有模型、原生队列和打字耗时。无人回应两轮后，计划也遵守长间隔下限。公开 API 不能撤销已在框架入队的主动任务。

## 本机状态

发言轮数、下次检查时间、待发标记、静默状态、话题摘要和单次联系计划原子写入插件标准 `data_dir/schedule.json`。摘要和计划含私聊信息，只保存在本机，不进 Git；日志只记录动作、数量和间隔，不记录正文或身份账号。调度查询最多回看 30 天的已有消息，话题独立按七天过期。

调用模型及入队前先持久化失败退避时间，得到有效决定后才更新下次检查。重启和配置重载不刷新次数，也不提前既有截止时间；旧状态缺少联系计划时按无计划读取。旧版 `attempts` 记录的是入队次数，升级时不当作实际发言；已有旧尝试时至少保留两小时休息。损坏状态会报错并停止加载，不自动清空。配置兼容原 `0.1.0` 格式。

依赖 `qqbot_identity`，使用公开配置、私聊、消息、LLM 与主动任务能力。卸载或本插件配置更新会取消后台任务。源码只部署于蓝铃，不参与棉花糖家族插件同步。
