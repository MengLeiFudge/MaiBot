# 公开答复

让 Planner 可以用 `send_reply` 直接发送已经写好的公开正文，减少再次调用 Replyer 改写的等待。原生 `reply` 继续保留；图片、附件和引用走原有完整处理路径。直接答复沿用原有人设、真实身份、记忆和知识证据，不更换模型、不降低推理强度。

复杂问题可以先发可靠且有用的阶段结论（`phase=progress`），再继续研究，有新证据后补充。工具不会强制结束本轮，不输出内部分析，也不要求简单闲聊拆成多条。

复制示例为本机 `config.toml`，启用 `plugin.enabled`，确认 `guard.bot_qq` 是本实例账号。依赖身份插件 0.1.1 及知识插件 0.2.1，确保直接答复前的 Planner 同样获得身份与证据。配合 `qqbot_reply_timing`，首条等待抵扣处理时间，后续发送按原速度执行。

工具只在原生 `reply` 已经可用、最新真实人类消息已进入本次上下文时开放；发送前再次核验会话和最新消息。群聊与私聊均适用，不跨会话发送。相同正文并发去重，失败、取消或未知结果不自动重发；成功发送仍经过原生发送服务并同步历史及记忆。仅保存最多 128 个会话的瞬时目标和本轮回执。
