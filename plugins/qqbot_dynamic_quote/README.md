# QQBot 动态引用

MaiBot SDK 2.7 原生出站 Hook 插件。它在 Platform IO 真正发送首条回复前，根据被回复消息与当前发送时刻之间的可见消息数量，动态决定是否保留引用。

## 行为

- 默认阈值为 5，可在 WebUI 或配置文件中调整。
- 同一会话中，目标消息之后间隔 0 至 5 条可见消息时取消引用；间隔 6 条及以上时保留引用。
- 可见消息包括用户、机器人、命令、文本、图片等已保存消息，不计入 `is_notify=true` 的协议事件。
- 群聊和私聊使用同一规则。
- 只处理发送链已经设置 `set_reply=true` 的消息；MaiBot 连续发送 A、B、C 时，Core 本来只给 A 设置引用，因此 B、C 不受影响。
- 目标消息不在当前会话、数据库查询失败或无法确定会话时保留原引用。
- 插件不修改消息正文，不写业务状态，也不直接调用 OneBot。

配置见 `config.example.toml`。
