# QQBot 自动复读

MaiBot SDK 2.7 原生被动事件插件。它只观察真人群聊中的纯文本消息；连续相同文本达到旧 QQBot 概率条件时，由公共 `qqbot.route.claim` 选择唯一实例，直接通过 NapCat 发送原文本，并中止当前消息进入 Planner、普通 LLM 和 A-Memorix。

## 行为

- 第二条连续相同文本起按 20% 概率尝试复读；后续每条增加 15%，最高 80%。
- 同一连续段最多复读一次；成功后同文本冷却 120 秒。
- 同一发送者和文本在 3 秒内的双实例重复事件不增加连续次数。
- 固定命令、@/唤醒消息、机器人消息、私聊、notice、图片、QQ 表情、引用和其他混合消息不参与复读。
- 状态只保存在插件进程内存，插件重载后清空；多实例出站唯一性由公共 claim 保证。

配置见 `config.example.toml`。新增固定命令入口时，应在 `command_filter.py` 增加代表性过滤并补回归测试，避免被动复读抢在 Command 调度前消费命令。
