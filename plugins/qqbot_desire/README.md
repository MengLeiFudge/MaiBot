# QQBot 性欲状态

蓝铃全身只有一份性欲值，群聊和私聊共用。它会随真实时间上涨，默认大约 12 小时从空到满。色情或挑逗的对话大约每两分钟再加 8，主人在私聊里这一轮的抚摸、亲吻、进入或其他身体刺激大约每一分钟再加 15。普通聊天不加，也不能直接把数值改成某个数。一次加不满。把 `config.example.toml` 复制为本机 `config.toml` 后，将 `[plugin].enabled` 设为 `true`。

规划器和回复器每次请求前读到档位，不读历史笔记：

- 35 以下保持平常，不提身体。
- 60 以下有感觉，但不说。
- 达到自己解决阈值前，主人私聊可以在答完后补一句；群聊不提。
- 达到阈值后仍然先回答当前内容。主人私聊里可以直说想要，也可以自己解决。群聊最多显得不专心。

`note_desire_rise` 只在这一轮确实发生了上述刺激时调用。`topic` 可用于当前会话，`physical` 只接受主人私聊。同一种刺激在间隔内重复调用会被拒绝。原因不写入后续提示。

`record_desire_action` 由模型自己决定是否调用。`self_relief` 只在达到阈值时成功；`shared` 只接受主人私聊，表示这轮确实和主人亲密过。成功后降到余韵和当前值中较低的一个，并追加一条本机笔记。笔记最多 120 字，最多保留 40 条，写在插件数据目录的 `desire.json`，不进 Git，也不注入后续群聊。

达到阈值且不在 00:00–08:00 时，至少每 45 分钟向已有主人私聊提供一次决定机会：先回未完成的正事，然后自己选择开口、自己解决或安静。没有已有私聊时不创建会话。对方先谈到时，仍按档位接，不是开场默认。

表达学习和行为学习保持原配置，本插件不清理已学说法。
