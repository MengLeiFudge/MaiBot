# 首条回复等待

通过公开接收、Planner 和发送 Hook 记录本轮处理时间。首条消息实际补等 `max(0, 原打字等待 - 已处理时间)`；后续分段保持框架原有速度。模型、推理强度、上下文和消息内容均由原有配置决定。

复制 `config.example.toml` 为本机 `config.toml`，设置 `plugin.enabled = true`，然后重启。发送速度继续读取 `response_post_process.typing_speed`。

只有真实收到且已经进入本次 Planner 上下文的消息才能抵扣。工具续轮不重置时钟；新源消息建立新一轮。瞬时状态最多保存 128 个会话，不保存正文、不写数据库。并发发送只允许一条抵扣；明确失败释放资格，取消或未知结果不自动重发。
