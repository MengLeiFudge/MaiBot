# QQBot RightCodes 生图

MaiBot SDK 2.x 原生插件，保留生图功能源码，与 AstrBot 侧同步维护：

- 群消息积分累计、积分查询和全局前 10 排行。
- 生图模型仅保留 `gpt-image-2.5`；每张 40 积分，对应人民币 0.04 元，沿用倍率 1000。
- 旧模型选择自动归一，积分余额不变；预扣、失败和超时原额退款机制保持不变。
- 向本机 CPA 的 OpenAI Images 接口请求生图，由 CPA 管理 HC/RC 渠道及优先级。两条渠道的 `gpt-image-2.5` 模型记录必须设置 `image: true`；只填写模型名会被 CPA 直接以 HTTP 400 拒绝。
- `生图模型` / `生图价格` 展示唯一模型；旧切换指令保留解析，但只接受 `gpt-image-2.5`，菜单不再推荐切换。
- 标准指令为 `文生图 提示词`、`图生图 提示词`，普通请求的提示词保留内部空白和换行，不调用聊天模型改写；命中豆豆眼预设时改用固定原文。图生图优先当前附件，否则取直接引用消息的单张图片；多图、缺图或读取失败在扣分前提示。
- `头像生图 提示词` 使用发送者头像，`头像生图 @某人 提示词` 指定目标（也可指定机器人）。目标艾特紧跟命令词；命令前艾特不作目标，额外艾特提示明确目标。原图在扣分前下载、验证，后续上传复用。
- `生成豆豆眼头像` 固定使用发送者头像，跳过分类和改写；`头像生图 豆豆眼`、附图/引用后 `图生图 豆豆眼`、旧生成入口和自然语言“帮我把我的头像改成豆豆眼风格”“把这张图改成豆豆眼”也支持同一预设。自然语言须先识别为实际改图请求并确定唯一来源，闲聊/否定不因关键词扣费。
- 豆豆眼请求的提示词完全替换为 `prompts/doudouyan.txt` 的完整中文预设（v2），按 UTF-8 字节读取，不翻译、拼接、截断或修改空白；所有入口开工均标明“提示词来源：用户话语（无预设）”或“提示词来源：豆豆眼预设（完整固定原文）”，预设另列原图来源。“无预设”不取消旧生成入口的既有条件改写。预设通知明确说明不追加其他描述；明确 `文生图` 始终走纯文字路径，旧 `生成` 引用纯文字消息时仍按普通请求处理。资源读取失败、多图或目标歧义不扣积分，其他生图规则保持原样。
- 视觉目标是用动漫相机拍摄头微微向右倾斜、脸朝右的大头照：优先保持大脸近景比例、自然取景裁边及头颈身体的连续关系，颈部或衣领随取景自然露出。以用户认可的头像和例图为位置标准，不为居中或展示完整头部而缩小脸。胶囊眼、无嘴无鼻和极简色面风格保持，颜色和小饰物在构图符合后再评估。预设区分头部与手、手持物、衣物、背景，从头发和皮肤各自区域取色；插件上传完整参考图，不执行自动裁剪，资源热读后下一次生图即生效。
- 自然语言路径在私聊或群内明确唤醒后评估，例如“画只猫”“能帮我画只猫吗”“P一下这张”“把我的头像改成水彩”；完整请求按相同价格直接执行，开工回显提示词和来源。能力询问、否定、评价旧图、单独发图不执行；历史依赖或来源歧义先提示补完整请求，不扣积分。
- `draw_intent.py` 负责本地候选和严格 JSON/来源校验，通过 `chat.receive.after_process` 公开 Hook 调用当前 `replyer`，再转换为明确指令组件复用原流程；不用向量库、不存解析会话。引用仅在当前正文明确要求时作素材。分类每用户1并发/10秒冷却/15秒截止，引用读取5秒；分类不可用回普通聊天，明确命令不受分类冷却影响。
- 旧“生成…”/“棉花糖生图…”入口保留原来的条件改写：命中上下文指代或存在参考图等情况时，用当前 `replyer` 整理提示词；整理失败不扣积分。
- 旧变体的当前图片与引用图片仍最多 3 张；新明确入口使用单图。单张最多 20 MiB；参考图通过 `/images/edits` multipart 上传，GIF 等格式取首帧转换为 PNG。文生图走 `/images/generations`，默认一张 `1024x1024` 图片。
- 以“生成”开头的消息通过固定命令入口直接生图，例如 `生成一只白猫的图片`、`生成一只白猫`；允许不带空格、多行提示词，不要求图片后缀，群聊无需 @。原 `棉花生图` / `棉花糖生图` 继续有效。
- 只有 `生成` 或其后只有空白时，提示补充文字，不扣积分、不进入聊天；生图、参考图整理及失败退款共用现有流程。
- 普通问答命中生图、接口路径、尺寸或模型关键词时，只向该次 replyer 请求临时注入当前模型、人民币价格和 Images 接口摘要。
- 成功和失败结果通过 NapCat 原生 API 引用原请求；成功结果附带随机本地摘要，不调用额外 LLM。
- 所有成品先验证为有效图片，PNG保留字节，其他格式转PNG并保留实际尺寸（结果和转换后均限制32 MiB），保存到既有运行数据根的 `draw/outputs/YYYYMMDD/`，使用时间和唯一标识命名，再发送本地文件；不自动清理或另存提示词元数据。
- 保存失败继续交付并明确标注“未保存”，交付成功正常扣分；保存和发送均失败时退款。已保存但发送失败时保留成品并告知文件名，不重新生图。
- 同一群消息只由 `points.owner_self_id` 累计一次；命令通过公共 claim 选择唯一实例。

本工作区的实际配置和示例配置均为 `plugin.enabled = false`，夜凛不运行生图业务；生图和积分的运行 owner 是 AstrBot 云栖。此处只同步源码，不启用夜凛业务插件。

`config.toml` 含真实 API Key，因此被插件仓库忽略。`config.example.toml` 是可提交模板。`rightcodes.base_url` 默认 `http://127.0.0.1:8317/v1`，`rightcodes.api_key` 填 CPA 客户端凭据；保留旧配置节名和业务数据存储路径。
